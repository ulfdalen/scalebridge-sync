Re-run history import

Fetch a window of past measurements from Withings and upload anything Garmin is missing. Measurements this app has already synced are skipped, so re-running is safe — it just takes as long as the window is wide.

Updates

Off by default. When enabled, this app — not your browser — asks GitHub once a day whether a newer release exists, and shows a pill on the dashboard if there is one. Nothing else is sent or received.

Change the port

This app listens on —. The port is baked into the callback URL your Withings application knows, so changing it here breaks the Withings connection until you update the portal to match. Only worth doing if something else on this computer wants the same port.
